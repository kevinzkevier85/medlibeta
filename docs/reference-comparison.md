# เทียบเว็บอ้างอิง 2 เว็บ กับ MedLib

อ่านจากโค้ดจริง (clone ไว้ที่ `_ref/`, ไม่ commit) — 2026-11-07

- **CVS-pdf** — github.com/apiwata90-design/CVS-pdf (เว็บ: `/` = ตัวอ่าน lecture, `/exams/` = ข้อสอบเก่า)
- **psu-quiz** — github.com/finn269/psu-quiz (เว็บหน้าเดียว "EXAM Quiz Builder", build 2026-11-03.2)

ทั้งสองเว็บทำเรื่องเดียวกัน คือฝึกทำข้อสอบเก่า Med PSU รายบล็อก แต่คิดคนละแบบ
- **CVS** = ผู้ดูแลเตรียมข้อสอบ + เฉลย + คำอธิบายให้ (ผ่าน pipeline/Claude) ผู้ใช้เข้ามา "ทำ" อย่างเดียว เน้นคุณภาพเฉลยและการโยงกลับไปอ่าน lecture
- **psu-quiz** = เครื่องมือให้ผู้ใช้ "สร้าง" คลังข้อสอบเอง (นำเข้า PDF → แยกข้อ → ใส่เฉลย) แล้วทำเอง เน้นความยืดหยุ่นและแก้ไขได้ทันที

## 1. CVS-pdf — ส่วนตัวอ่าน lecture (`index.html`)

| ฟังก์ชัน | ข้อดี | ข้อเสีย |
|---|---|---|
| ตัวอ่าน PDF ในเว็บ (PDF.js) เลื่อนต่อเนื่อง, ซูมเข้า/ออก/พอดีกว้าง, พิมพ์เลขหน้า, แถบหน้าติดด้านบน | อ่านได้ในเว็บเลย ไม่ต้องเปิดแอปอื่น | ค้นหาข้อความใน PDF ไม่ได้ |
| รายชื่อ lecture ด้านซ้าย + ช่องค้นหาชื่อ + ปุ่ม lecture ก่อนหน้า/ถัดไป | หาไฟล์เร็ว อ่านต่อเนื่องเป็นลำดับ | ค้นได้แค่ชื่อไฟล์ |
| ติ๊ก "อ่านจบแล้ว" + แถบความคืบหน้า % ทั้งบล็อก | เห็นว่าอ่านไปเท่าไร | เก็บในเครื่องเดียว ไม่ข้ามเครื่อง |
| จำตำแหน่งที่อ่านค้างรายไฟล์ (หน้า + ตำแหน่งในหน้า) และไฟล์ล่าสุด | เปิดมาอ่านต่อได้ทันที | — |
| Profile หลายแท็บ (ตั้งชื่อเอง), เลือกหลายไฟล์ (Shift เลือกช่วง) ย้ายไป profile อื่น | แยกกองไฟล์ เช่น "ก่อนสอบ" / "อ่านแล้ว" | แนวคิดเข้าใจยาก ซ้อนกับ "บล็อก" |
| ลากเรียงลำดับ, เรียงตามชื่อ, เปลี่ยนชื่อ (ดับเบิลคลิก / กดค้างบนมือถือ), ลบ (ถามยืนยัน "ลบ?") | จัดรายการเองได้ครบ | — |
| เพิ่ม PDF ของตัวเอง (ลากวาง/เลือกไฟล์) เก็บใน IndexedDB, กันไฟล์ซ้ำด้วยขนาดไฟล์ | ใช้กับไฟล์ส่วนตัวได้ | กินพื้นที่เบราว์เซอร์ อาจเต็ม |
| รายชื่อ lecture กลางจาก `lectures/index.json` โหลดไฟล์จริงตอนเปิดครั้งแรก มี % ดาวน์โหลด แล้วเก็บไว้ในเครื่อง | เปิดครั้งต่อไปเร็ว/ออฟไลน์ได้ | PDF อยู่ใน git repo (659 MB, จำกัดไฟล์ละ 100 MB) |
| ลิงก์ดาวน์โหลดโฟลเดอร์ Drive ล็อกด้วยรหัส (AES + PBKDF2 600k รอบ) | แชร์ลิงก์ในเว็บสาธารณะได้โดยไม่เปิดเผย | ต้องบอกรหัสกันเอง |
| โหมดสว่าง/มืด (ใช้ร่วมกับหน้าข้อสอบ) | สบายตา | — |
| มือถือ: รายชื่อเป็นลิ้นชักเลื่อนออก, กดค้างแทนดับเบิลคลิก | ใช้บนมือถือได้จริง | — |
| PWA: ติดตั้งเป็นแอป, เปิดออฟไลน์ได้ (service worker) | เหมือนแอปจริง | ต้องเปลี่ยนเลข cache ทุกครั้งที่อัปเดต |
| Deep link `#lecture=<ไฟล์>&page=N` จากหน้าข้อสอบ เปิดในแท็บเดิมแท็บเดียว | กด "อ่านเพิ่ม" แล้วไปหน้าที่อ้างถึงทันที ไม่เปิดแท็บรก | — |

## 2. CVS-pdf — ส่วนข้อสอบ (`exams/`)

โครงสร้าง: หน้ารวม + **ไฟล์ HTML 1 ไฟล์ต่อ 1 ชุด** (ฝังข้อมูลไว้ในไฟล์ 0.4–1.2 MB)

| ฟังก์ชัน | ข้อดี | ข้อเสีย |
|---|---|---|
| หน้ารวม: การ์ดรุ่น (52, 51, …) → MCQ / KF / OSPE พร้อมจำนวนข้อ, แถบความคืบหน้า, "ยังไม่มี" ถ้าขาด | เห็นภาพรวมทั้งบล็อกในหน้าเดียว | เขียนมือ/สร้างด้วยสคริปต์ ไม่มีค้นหา |
| แท็บ ทำข้อสอบ / Guidereader / สรุปผล | แยกงานชัด | — |
| แถบเลขข้อด้านบน สีตามสถานะ (ถูก/ผิด/ถูกบางส่วน/ปักธง/ตอบแล้วรอตรวจ), ปุ่ม "ดูทั้งหมด", "ทำแล้ว x/y" | กระโดดข้อได้ทันที เห็นภาพรวม | ชุดยาวแถบยาวมาก |
| โหมด ฝึก (เฉลยทันที) / จับเวลา (เวลาสอบจริงของชุด, หมดเวลาส่งอัตโนมัติ) | เหมือนสอบจริง | เปลี่ยนโหมด = ล้างคำตอบทั้งหมด |
| ตัวกรอง: ตาม Lecture, ตามสถานะ (ผิด / ปักธง / ยังไม่ทำ) | ฝึกเฉพาะเรื่อง/เฉพาะจุดอ่อน | — |
| MCQ: ช้อยส์มีวงกลมตัวอักษร, เฉลยแล้วโชว์ "ทำไมช้อยส์นี้ผิด/ถูก" ใต้ทุกตัว | เรียนจากช้อยส์ผิดได้ | ต้องมีคนเขียน why ทุกช้อยส์ |
| KF/OSPE: กล่องสถานการณ์/สถานี, ข้อย่อยแบบพิมพ์ตอบ (ตรวจอัตโนมัติด้วยคำที่ยอมรับ/คำสำคัญ) และแบบเลือกหลายข้อ (เลือกเกินได้ 0), คะแนนบางส่วน, ปุ่ม "ตัดสินเอง ถูก/ผิด/อัตโนมัติ" | รองรับข้อสอบครบทุกประเภทของคณะ | ตรวจคำตอบพิมพ์ด้วยคำสำคัญยังพลาดได้ |
| กล่องคำอธิบาย: บรรทัดคำตอบ, เฉลยต้นฉบับ (ถ้าไม่ใช้), ลำดับกลไกเป็นลูกศร, หลักการ (แตกเป็นข้อ ๆ อัตโนมัติ), กล่อง ⚠️ จุดที่มักสับสน, หมายเหตุการตรวจเฉลย | อ่านง่าย เป็นระบบมาก | ข้อมูลต้องเตรียมละเอียด (ต้นทุนสูง) |
| ป้ายเฉลย: "เฉลยต้นฉบับอาจคลาดเคลื่อน" / "แก้เฉลยจากต้นฉบับแล้ว" / "เฉลยยังไม่ยืนยัน" | ซื่อสัตย์เรื่องความแม่นของเฉลย | — |
| "อ่านเพิ่ม": ลิงก์ lecture + หน้า, ป้าย "ออกซ้ำ n ปี" / "Tier" | โยงข้อสอบ → lecture หน้าที่ต้องอ่าน | — |
| ปุ่ม "เฉลยข้อนี้น่าสงสัย" → หน้าสรุปรวมรายการ + ปุ่ม "คัดลอกรายการ" ไปวางให้ Claude ตรวจซ้ำ | วงจรแก้เฉลยกับ AI ง่าย | เก็บในเครื่อง ไม่ส่งถึงผู้ดูแลอัตโนมัติ |
| รูปประกอบ กดขยายเต็มจอ | ดูรูป OSPE ชัด | — |
| คีย์ลัด ← →, A–E / 1–5 | ทำเร็ว | — |
| **โหมดทำซ้ำ**: สุ่มลำดับ ข้อที่ผิดจะวนกลับมาอีกหลัง 2 ข้อ จนถูกครบทุกข้อ, แถบผ่าน x/y, จบแล้วตาราง "พลาดกี่ครั้งก่อนผ่าน + ต้องอ่านหน้าไหน" + วนอีกรอบเฉพาะข้อที่เคยพลาด | ฝึกจนจำได้จริง (คล้าย flashcard) | — |
| สรุปผล: คะแนน, ตารางคะแนนราย Lecture เรียงจากอ่อนสุด + ปุ่มกระโดดไปข้อที่ผิด | รู้จุดอ่อนรายเรื่อง | ไม่มีประวัติย้อนหลังหลายรอบ |
| **Guidereader**: "อ่านอะไรก่อนทำชุดนี้" แยกตาม Lecture, Tier 1–3 (ต้องอ่าน/ควร/ถ้ามีเวลา), ช่วงหน้า, ประเด็นที่ออกแต่ละปี, แถบสัดส่วนข้อต่อ lecture, ชุดหน้าขั้นต่ำครอบคลุม x% + "อ่านซ่อมจากข้อที่ผิด" | เปลี่ยนข้อสอบเก่าเป็นแผนอ่านหนังสือ | ต้องวิเคราะห์ข้ามทุกรุ่นก่อน (งานหนัก) |
| ปุ่มรีเซ็ต + "เลิกทำ" (undo) 6 วินาที | กันกดพลาด | — |
| เก็บคำตอบรายชุดใน localStorage | ปิดเปิดใหม่ทำต่อได้ | ไม่ข้ามเครื่อง, ไม่มีสำรองข้อมูล |

## 3. psu-quiz (`index.html` หน้าเดียว + `data.json`)

แท็บ: ① นำเข้า PDF → ② โปรเจกต์ → ③ แก้ไข/เฉลย → ④ ทำข้อสอบ → ⑤ ผลคะแนน

| ฟังก์ชัน | ข้อดี | ข้อเสีย |
|---|---|---|
| นำเข้า PDF: ดึงข้อความในเบราว์เซอร์, ตัดหัว/ท้ายกระดาษที่ซ้ำทุกหน้าออกเอง, กล่องข้อความดิบแก้ได้ก่อนแยก | ไม่ต้องใช้ AI/เซิร์ฟเวอร์ | PDF สแกน/ภาษาไทยวรรณยุกต์เพี้ยนจะพัง |
| แยกข้ออัตโนมัติ (เลขข้อ + A–E), ตรวจปัญหา (ไม่พบโจทย์/ช้อยส์ไม่ครบ/เลขข้อซ้ำ), พรีวิว 3 ข้อแรก | สร้างคลังข้อสอบเองได้เร็ว | รองรับแค่ MCQ 5 ช้อยส์ |
| นำเข้า JSON ได้หลายรูปแบบ | รับข้อมูลจากที่อื่น | — |
| โปรเจกต์ (= บล็อก) → ชุดข้อสอบ: สร้าง/ตั้งชื่อใหม่/ลบ, เลื่อนชุดขึ้นลง, ส่งออกรายชุด/รายโปรเจกต์ | จัดคลังเองได้อิสระ | ใช้ prompt/confirm ของเบราว์เซอร์ หน้าตาเก่า |
| แก้ไข/เฉลย: แก้โจทย์, ช้อยส์, เลือกคำตอบ (มี "ทุกตัวเลือกถูก"), คำอธิบาย, แนบรูป (ถ่ายจากกล้องได้ บีบอัดเหลือ 1000px), เพิ่ม/ลบข้อ, "แสดงเฉพาะข้อที่ต้องตรวจ" | แก้ข้อผิดได้ทันทีโดยไม่ต้องรอใคร | รูปเก็บใน localStorage (เต็มง่าย ~5 MB) |
| **วางเฉลยจาก Claude**: วางข้อความเฉลยรูปแบบไหนก็ได้ ("ตอบ: A", "1. B", markdown) → ตรวจ → จับคู่เลขข้อ → นำเข้า, เลือกเขียนทับหรือไม่ | ใส่เฉลยทั้งชุดในครั้งเดียว | เฉลยไม่ผ่านการตรวจ (เชื่อ AI ทั้งหมด) |
| ทำข้อสอบ: โหมดสอบ / ฝึก, ติ๊ก **สุ่มข้อ** / **สุ่มช้อยส์** | กันจำตำแหน่งคำตอบ | ไม่มีจับเวลา, ไม่มีแถบเลขข้อ, ไม่มีคีย์ลัด |
| ปุ่ม "ไม่ชัวร์?" (โหมดสอบ) → หลังส่งทำเฉพาะข้อที่ไม่ชัวร์ซ้ำ | ทบทวนข้อที่เดา | — |
| **แก้ไขด่วนระหว่างทำ**: แก้โจทย์/เฉลยในหน้าทำข้อสอบ แล้วคะแนนคำนวณใหม่ทันที | เจอเฉลยผิดแก้ได้เลย | — |
| โหมดฝึก: นับคะแนนจากครั้งแรกที่ตอบ, จบแล้ว "ทบทวนข้อที่ตอบผิด" เป็นรอบ ๆ จนไม่เหลือ | ฝึกซ้ำจนถูก | ทำค้างแล้วรีเฟรช = หาย (ไม่ได้บันทึกระหว่างทำ) |
| **โน้ตลอย** 📝 มุมขวาล่าง รายชุด (จดศัพท์) | จดระหว่างทำได้ | โน้ตเป็นก้อนเดียวต่อชุด ไม่ผูกกับข้อ |
| ผลคะแนน: x/ข้อที่มีเฉลย, **ประวัติย้อนหลัง 20 ครั้ง** (วันเวลา + %), ดูผลครั้งล่าสุดซ้ำได้, เฉลยรายข้อ, ติ๊กเลือกข้อผิดที่จะทำซ้ำ, ทำทั้งชุดอีกครั้ง | เห็นพัฒนาการ | ไม่แยกคะแนนราย lecture |
| **ซิงก์ข้ามเครื่องผ่าน GitHub**: ส่งออก `data.json` → อัปโหลดขึ้น repo → อีกเครื่องกด "ดึงข้อมูล" (รวมระดับโปรเจกต์), เครื่องใหม่ที่ว่างโหลดเอง | ไม่ต้องมีเซิร์ฟเวอร์ | ทำมือ, ข้อมูลส่วนตัว (ประวัติ/โน้ต) ขึ้น repo สาธารณะ, รวมแล้วทับกัน |
| สำรองข้อมูล: เลือกที่บันทึกได้ (Save picker) / แชร์ไฟล์บนมือถือ | สะดวกบนมือถือ | — |
| "ไม่ส่งข้อมูลออกจากเครื่อง ไม่ใช้ API" | เป็นส่วนตัว | — |
| ป้าย build ทุกครั้งที่แก้ (`build YYYY-MM-DD.N`) | รู้ว่าเวอร์ชันไหน | — |

ข้อมูลใน `data.json` ตอนนี้: 3 โปรเจกต์ (med respi 11 ชุด, usmle 0, cvs 13 ชุด) ~1,300 ข้อ MCQ ล้วน, มีรูป 20 ข้อ

## 4. MedLib ตอนนี้ (v0.4.0) เทียบกับสองเว็บ

มีแล้ว: หลายบล็อกในเว็บเดียว, lecture + ตัวอ่าน PDF (Drive), ข้อสอบเป็นชุดแบบ CVS (ฝึก/จับเวลา, ตารางข้อ, ตัวกรอง, ปักธง, สรุปผล, ทำซ้ำข้อที่ผิด, คีย์ลัด), ค้นหาข้ามบล็อก, ตั้งค่า, ฟอร์มเพิ่มข้อสอบ, ส่งออก/นำเข้าข้อมูลส่วนตัว, เฉลยผ่าน Auditor (สถานะ disputed/draft), dark mode, เวอร์ชัน + changelog

ยังไม่มี (จากสองเว็บนี้):

| จาก CVS | จาก psu-quiz |
|---|---|
| Guidereader (อ่านอะไรก่อนสอบ + Tier + อ่านซ่อม) | นำเข้า PDF/แยกข้อในเบราว์เซอร์ |
| ปุ่ม "เฉลยน่าสงสัย" + คัดลอกไป Claude | วางเฉลยจาก Claude |
| ลำดับกลไก / กล่องจุดสับสน / why รายช้อยส์ (ขึ้นกับข้อมูล) | แก้ไขข้อ/เฉลยระหว่างทำ |
| KF / OSPE (พิมพ์ตอบ, เลือกหลายข้อ, คะแนนบางส่วน) | สุ่มข้อ / สุ่มช้อยส์ |

## 5. คำถามทั้งหมด (ตอบในแชททีละรอบ)

### A. ภาพรวม
1. ใครใช้เว็บนี้: เราคนเดียว / เพื่อนในรุ่น / ทั้งคณะ (สาธารณะ)
2. ใครเป็นคนสร้างเนื้อหาข้อสอบ: Claude (Auditor) อย่างเดียว / ผู้ใช้สร้างเองในเว็บได้ด้วย / ทั้งสอง
3. ใช้ทำอะไรมากที่สุด: ทำข้อสอบ / อ่าน lecture / วางแผนอ่าน
4. อุปกรณ์หลัก: มือถือ / iPad / คอม · ต้องใช้ออฟไลน์ไหม

### B. การทำข้อสอบ
5. โหมดที่ต้องการ: ฝึก, จับเวลา, สอบไม่จับเวลา · เปลี่ยนโหมดแล้วล้างคำตอบไหม
6. สุ่มข้อ / สุ่มช้อยส์
7. วิธีทำซ้ำ: แบบ CVS (ผิดแล้ววนกลับมาหลัง 2 ข้อ) / แบบ psu (จบรอบแล้วทำเฉพาะข้อผิดเป็นรอบใหม่) / ทั้งสอง
8. ปักธงหมายถึงอะไร: "ไว้ทบทวน" / "ไม่ชัวร์ (เดา)" / แยกสองปุ่ม
9. ทำข้อสอบข้ามชุด: รวมทุกรุ่นตาม lecture/หัวข้อ, สุ่ม n ข้อจากทั้งบล็อก
10. KF / OSPE ต้องการไหม · ตรวจคำตอบพิมพ์อัตโนมัติหรือให้ตัดสินเอง

### C. เฉลยและคำอธิบาย
11. ความละเอียดของคำอธิบาย: สั้น / แบบ CVS เต็ม (กลไก, จุดสับสน, why ทุกช้อยส์)
12. ข้อที่เฉลยต้นฉบับไม่ตรงกับ AI: แสดงทั้งสองพร้อมป้าย / แสดงเฉพาะเฉลยที่ตัดสินแล้ว
13. ปุ่ม "เฉลยน่าสงสัย": คัดลอกไป Claude / ส่งเข้าคิวให้ผู้ดูแลอัตโนมัติ
14. ให้ผู้ใช้แก้เฉลยในเว็บได้ไหม (แก้เฉพาะเครื่องตัวเอง vs เสนอแก้ให้ทุกคน)

### D. lecture และการอ่าน
15. Guidereader ต้องการไหม · Tier คิดจากอะไร
16. ติ๊กอ่านจบ / % การอ่าน / จำหน้าที่อ่านค้าง
17. เพิ่ม PDF ของตัวเองได้ไหม · Profile
18. PDF มาจาก Drive (ตอนนี้) หรือเก็บใน repo แบบ CVS

### E. ข้อมูลส่วนตัวและซิงก์
19. ประวัติคะแนนย้อนหลัง, กราฟพัฒนาการ
20. โน้ต: ก้อนเดียวต่อชุด / ต่อข้อ / ต่อ lecture
21. ซิงก์ข้ามเครื่อง: ไม่ต้อง / ไฟล์ส่งออก-นำเข้า / GitHub data.json / บัญชีออนไลน์

### F. หน้าตาและการนำทาง
22. หน้าแรก: บล็อก → รุ่น → ประเภท (ตอนนี้) หรือแบบอื่น
23. ธีม: คง gentian violet ของ MedLib / ใช้สีตามบล็อก (CVS แดงเส้นเลือด)
24. หน้าทำข้อสอบ: แท็บแบบ CVS / หน้าเดียวยาว · แถบเลขข้อแบบไหน
