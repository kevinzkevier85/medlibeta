ในหนึ่งบล็อกมีอะไรบ้าง

หนึ่งบล็อกเท่ากับหนึ่งโฟลเดอร์ เวลาเพิ่มบล็อกใหม่ก็แค่สร้างโฟลเดอร์ใหม่ตามแบบเดิม ผมเลือกใช้ไฟล์ JSON เพราะเปิดอ่านได้ แก้ด้วยมือได้ และ GitHub เก็บประวัติให้ทุกครั้งที่แก้

ไฟล์ PDF จริงไม่อยู่ใน repo มีแค่ลิงก์ไป Drive 
{
  "id": "END-52-MCQ-005",
  "block": "END",
  "cohort": 52,
  "type": "MCQ",
  "stem": "หญิง 35 ปี ปัสสาวะ 6 L/วัน ...",
  "options": { "A": "...", "B": "...", ... },
  "answer": "B",
  "answer_status": "verified",
  "explanation": "...",
  "refs": [
    { "lecture": "END-L02", "pages": [14, 15] }
  ],
  "tags": ["ADH", "diabetes insipidus"]
}
ข้อสอบหนึ่งข้อ: ช่อง refs ผูกข้อสอบกับหน้า lecture ส่วน answer_status บอกว่าเฉลยยืนยันแล้ว หรือยังเป็นร่าง/ยังมีข้อโต้แย้ง

คำสั่งที่ MCP server จะมีให้ Claude

list_blocks ดูว่ามีบล็อกอะไรบ้าง · search ค้นคำทั้ง lecture และข้อสอบ เลือกได้ว่าบล็อกไหน · get_question เปิดข้อสอบหนึ่งข้อพร้อมเฉลย · get_lecture_page อ่านข้อความหน้าที่ต้องการ · add_question / add_lecture เพิ่มข้อมูล · sync_drive เช็กไฟล์ใหม่ใน Drive

เพิ่มข้อมูลได้ 2 ทาง แต่ได้ format เดียวกัน

ฟอร์มในเว็บกับ Claude (ผ่าน MCP) ส่งข้อมูลเข้าตัวตรวจตัวเดียวกัน ซึ่งอ่านกติกาจาก schema/ ชุดเดียว ถ้าข้อมูลไม่ครบหรือผิดรูปแบบ ระบบจะไม่รับ ไม่ว่าจะมาจากทางไหน ข้อจำกัดคือหน้าเว็บเขียนไฟล์ลง GitHub เองไม่ได้ สิ่งที่เพิ่มผ่านฟอร์มจึงเก็บเป็นข้อมูลส่วนตัวในเบราว์เซอร์ก่อน ถ้าจะให้เป็นค่ากลางของทุกคน ให้กด "ส่งออก" แล้วให้ Claude นำเข้า repo

ค่ากลาง กับ ค่าส่วนตัว

เว็บอ่าน defaults.json จาก GitHub ก่อน แล้วเอาค่าที่แต่ละคนปรับไว้ในเบราว์เซอร์มาทับเฉพาะเรื่องที่ปรับ ในหน้าตั้งค่ามีปุ่มรีเซ็ตกลับค่ากลาง และปุ่มส่งออก/นำเข้าค่าส่วนตัว ไว้กันค่าหายตอนล้างข้อมูลเบราว์เซอร์

ตกลงแล้ว

Drive แชร์แบบ "ทุกคนที่มีลิงก์" ไม่ต้องล็อกอิน

เว็บโหลด PDF ทั้งไฟล์จาก Drive มาเปิดในตัวดูของเราเอง จึงเปิดตรงไปที่หน้าที่ต้องการได้ ข้อควรรู้คือใครมีลิงก์เว็บหรือลิงก์ Drive ก็เปิดไฟล์และข้อสอบได้ทั้งหมด

ตกลงแล้ว

sync กับ Drive ผ่าน Google Drive for Desktop

รายชื่อไฟล์ PDF เว็บอ่านจาก Drive โดยตรง จึงเห็นไฟล์ใหม่ทันที ส่วนข้อความกับข้อสอบใช้คำสั่ง sync ที่เช็กว่าไฟล์ไหนใหม่หรือเปลี่ยน ถ้าต่อไปอยากให้อัตโนมัติค่อยเพิ่ม GitHub Actions
