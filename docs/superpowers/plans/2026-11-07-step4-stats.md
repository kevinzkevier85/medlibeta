# ขั้น 4: หน้าสถิติส่วนตัว — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** หน้า `#/stats` แสดงคะแนนรายบล็อกและรายหัวข้อ เรียงหัวข้อที่อ่อนสุดขึ้นก่อน กราฟคะแนนแต่ละรอบตามเวลา และปุ่ม "ฝึกหัวข้อที่อ่อนสุด"

**Architecture:**
- คำนวณใน `lib/quizcore.js` เป็นฟังก์ชันล้วน `groupStats` (เทสด้วย Node)
- หน้าเว็บอยู่ใน `quiz.js` (`viewStats`) ซึ่งมี `blockResults`, `chartSVG`, `makeMix` อยู่แล้ว
- `app.js` เพิ่ม route `stats` และปุ่มในแถบเครื่องมือ

**Tech Stack:** JS ไม่มี build step, Node (เทส), Playwright

**Spec:** `docs/superpowers/specs/2026-11-07-medlib-roadmap-design.md` § ขั้น 4 · ต่อจาก branch `finn-topic-tags` (PR #16, ยังไม่ merge)

## Global Constraints
- คะแนนใช้ **ผลล่าสุดของแต่ละข้อ** (`latestResults`) และ **ไม่นับข้อเฉลยรอยืนยัน** (`counts`)
- คะแนนของกลุ่ม = ค่าเฉลี่ยคะแนนล่าสุดของข้อที่ทำแล้ว (KF ได้คะแนนบางส่วน) เป็น % ปัดเป็นจำนวนเต็ม
- เรียงอ่อนสุดก่อน · กลุ่มที่ยังไม่ได้ทำเลยอยู่ท้าย · ปุ่ม "ฝึกหัวข้อที่อ่อนสุด" เลือกจากหัวข้อที่ทำแล้วอย่างน้อย 5 ข้อ
- กราฟเป็น SVG ในหน้า ไม่ใช้ไลบรารีเพิ่ม · ข้อความไทย · ออกเวอร์ชันถัดจาก main ตอนส่ง

## Review Focus
1. ยังไม่เคยทำข้อสอบเลย → หน้าแสดง "ยังไม่มีข้อมูล" ไม่พัง ไม่มี NaN (เทส Task 2)
2. ทำแต่ข้อที่ไม่นับคะแนน → ไม่มีหัวข้อใดได้ 0% หลอก ๆ (เทส Task 1)
3. บล็อกที่ไม่มีหัวข้อ (DEMO) → แสดงแค่คะแนนบล็อก ไม่มีตารางหัวข้อ (เทส Task 2)
4. ไม่มีหัวข้อไหนทำครบ 5 ข้อ → ไม่มีปุ่ม "ฝึกหัวข้อที่อ่อนสุด" (เทส Task 2)
5. รอบเดียว → ไม่มีกราฟ แต่มีข้อความ "ทำครบ 2 รอบขึ้นไปจะเห็นกราฟ" (เทส Task 2)

### Task 1: `groupStats` ใน quizcore

**Files:** Modify `lib/quizcore.js` (+ export) · Test `_test/quizcore.test.cjs`

**Interfaces:**
- Produces: `groupStats(qs, res, keyOv, keyOf) -> [{key, total, done, ok, pct}]`
  - `qs`: ข้อในบล็อก · `res`: ผลจาก `latestResults` · `keyOf(q)` คืนชื่อกลุ่ม (หรือ falsy = ข้าม)
  - `total`: ข้อที่นับ · `done`: ข้อที่นับและมีผล · `ok`: ผล ≥ 0.999 · `pct`: `round(100 * mean(res of done))`, `null` ถ้า `done = 0`
  - เรียง: มี pct ก่อน (น้อย → มาก, เสมอกันเรียง key) แล้วตามด้วย pct `null`
  - กลุ่มที่ `total = 0` ไม่ใส่

  - ลำดับ = `["thyroid", "adrenal", "lipid"]`
  - ข้อ draft ในกลุ่ม → ไม่นับใน total/done · กลุ่มที่มีแต่ข้อ draft → ไม่อยู่ในผล
