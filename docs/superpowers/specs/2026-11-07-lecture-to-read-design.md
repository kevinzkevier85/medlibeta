# ตอบผิดแล้วต้องอ่าน lecture ไหน — design

วันที่: 2026-11-07 · ผู้ตัดสินใจ: Finn · สถานะ: รอตรวจ

## เป้าหมาย
ตอบผิดแล้วนักศึกษารู้ทันทีว่าต้องไปอ่าน **lecture บทไหน** (ไม่ต้องบอกเลขหน้า) เห็นได้ 3 ที่: กล่องเฉลยใต้ข้อ, หน้าสรุปผลหลังจบรอบ, หน้าสถิติ

## สภาพตอนนี้
- **CVS (300 ข้อ):** ทุกข้อมี `refs` ชี้ lecture + หน้าแล้ว ขึ้น "อ่านเพิ่ม" ในกล่องเฉลย และหน้าสรุปผลมีตาราง "คะแนนราย Lecture" อยู่แล้ว
- **END (595 ข้อ):** `refs` ชี้แค่หน้าข้อสอบ/เฉลยต้นฉบับ (`paper`) ยังไม่มีข้อไหนชี้ lecture เลย ทั้งที่มี lecture 30 บท

## ที่ผู้ใช้เลือก
- ละเอียดแค่ชื่อ lecture (ไม่มีเลขหน้า)
- ผูกข้อ END กับ lecture ด้วย AI ทีละข้อ (1–2 บทต่อข้อ จาก 30 บทของ END) แบบเดียวกับตอนติดหัวข้อ
- แสดงทั้ง 3 ที่

## ข้อมูล
- `data/blocks/END/topics.json` เพิ่ม `"lectures": { "<qid>": ["L14"], … }`
- `tools/apply_topics.cjs` เขียนลงข้อสอบเป็น ref แบบไม่มีเลขหน้า `{ "lecture": "L14" }` ต่อท้าย `refs` เดิม
  - ref ของ `paper` ยังอยู่ครบ
  - ไม่ซ้ำกับ ref เดิม
  - รันซ้ำแล้วผลเหมือนเดิม
  - lecture id ที่ไม่มีในบล็อก → หยุดและบอก (เหมือน topic id ผิด)
  - ตัวสร้างทั้ง 3 ตัวเรียก apply_topics อยู่แล้ว จึงสร้างใหม่แล้วไม่หาย
- `lib/validate.js`: ref ของ `lecture` ไม่ต้องมี `pages` ก็ได้ (ถ้ามีต้องถูกเหมือนเดิม) · `paper` ยังต้องมี `pages`
- CVS ไม่แตะ

## หน้าเว็บ
1. **กล่องเฉลยใต้ข้อ** (`quiz.js`, ส่วน refs)
   - ตอบผิดหรือได้บางส่วน: แถบเด่นบนสุด "ควรอ่าน: L14 Calcium phosphate regulating hormone" กดแล้วเปิด lecture บทนั้น
   - ตอบถูก: ลิงก์ "อ่านเพิ่ม" ตัวเล็กเหมือนเดิม
   - ref ที่ไม่มีหน้า แสดงแค่ชื่อบท ไม่มี "หน้า …"
2. **หน้าสรุปผล:** หัวข้อ "Lecture ที่ควรอ่านก่อน" อยู่เหนือตาราง "คะแนนราย Lecture" แสดง lecture ที่มีข้อผิดในรอบนี้ เรียงจากผิดมากไปน้อย พร้อมจำนวนข้อ และลิงก์เปิด lecture
3. **หน้าสถิติ:** ในการ์ดของแต่ละบล็อก มีตาราง "Lecture ที่ผิดบ่อย" 5 อันดับ
   - นับจากผลล่าสุดของแต่ละข้อ (คะแนน < 1) และไม่นับข้อที่เฉลยยังไม่ยืนยัน
   - คอลัมน์: Lecture / ผิด / ลิงก์ "อ่าน"
   - ไม่มีข้อผิด → ไม่แสดงตาราง

ลิงก์ "อ่าน" เปิดโหมด Lecture ที่บทนั้น (`#/lec/<block>/<lecture>`) ตามที่เว็บใช้อยู่

## ทดสอบ
- **`_test/validate.test.cjs`:** ref lecture ที่ไม่มี pages ผ่าน · ref paper ที่ไม่มี pages ไม่ผ่าน
- **`_test/apply_topics.test.cjs`:**
  - เขียน ref lecture
  - ไม่ซ้ำ
  - รันซ้ำแล้วไม่เปลี่ยน
  - lecture id ผิด → throw และไม่เขียนอะไรเลย
- **Playwright:**
  - ตอบผิดข้อ END → ขึ้น "ควรอ่าน: …"
  - จบรอบ → หน้าสรุปมี "Lecture ที่ควรอ่านก่อน"
  - หน้าสถิติมี "Lecture ที่ผิดบ่อย"
  - ไม่มี pageerror
- **สุ่มตรวจการผูก:** 45 ข้อ แก้ที่ผิด แล้วไล่หาข้อคล้ายกันแบบตอนติดหัวข้อ

## ความเสี่ยง
- AI ผูกบางข้อผิดบท → เพื่อนแจ้งได้ผ่านปุ่มแจ้งเฉลย
- lecture บางบทซ้ำกัน (เช่น L7 กับ SDL2 Pituitary hormones) → เลือกได้ 2 บท
